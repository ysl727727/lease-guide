# 프로젝트 노트 — 허위매물 탐지 어시스턴트

## STEP 1. 문제 정의

**허위매물 탐지 어시스턴트**

매물 광고 정보를 국토교통부고시 「부당한 중개대상물 표시·광고행위의 유형 및 기준」
(제2026-345호, 2026.7.3. 일부개정)에 대조해 부당 표시·광고 해당 여부와 유형을
판정하는 어시스턴트에 사용할 로컬 모델을 선정한다.

- 사용자: 부동산 플랫폼 매물 검수 담당자
- 답해야 할 질문: 광고가 고시 기준에 해당하는지, 어느 유형인지, 근거는 무엇인지
- 한국어 성능: 중요 (기준·광고·판정이 모두 한국어)
- 데이터 통제: 미검수 매물 정보와 중개사 정보가 포함되므로 로컬 운영에 근거가 있음
- 응답 속도: 중요도 중간 (실시간 대화가 아닌 검수 배치 작업)
- GPU 환경: RTX 5060 Laptop 8GB

**자료 제공 방식**: 고시 조항을 프롬프트에 직접 포함. 검색·RAG 없음(in-context QA).

## 관찰 사항

### tokens/s가 실행 중 변동함
1차 실험에서 gemma3의 tokens/s가 Q01~Q06 구간 71~79, Q07 이후 102로 뛰었다.
같은 모델·같은 설정인데 약 40% 차이가 난다. GPU 전력 상태나 백그라운드 부하의
영향으로 보이며, 모델의 성능 차이로 해석해서는 안 된다.
qwen3는 전 구간 약 102로 일정했다.

→ 평균만 표시하면 이 변동이 묻히므로, 최소/최대와 함께 기록한다.

### 입력 토큰 수가 모델별로 다름
같은 질문인데 qwen3의 `prompt_eval_count`가 gemma3보다 60~90 토큰 많다.
토크나이저가 달라서 생기는 차이이며, tokens/s만으로 체감 속도를 비교하면 안 되는 이유다. 
전체 응답 시간을 함께 본다.

### VRAM
- gemma3: 2742.3 MiB (일관)
- qwen3: 3030.9 MiB (일관)
- `client.ps()`의 `size_vram`을 각 응답 직후 조회한 값이며, 최대 VRAM 사용량이 아니다.

### Q06 재현성 관찰
temperature=0, seed=42 고정에도 qwen3의 Q06은 r1(out=1024, 한도 도달)과
r2(out=490, 정상 종료)가 달랐다. 나머지 9개 문항은 r1/r2가 토큰 수까지 동일했다.
결정론적 설정에서도 특정 입력에서는 재현이 보장되지 않을 수 있음을 보여주며,
질문별 2회 반복의 필요성을 뒷받침하는 관측이다.

### Q08 정답 근거 보강
'현저하게'에 대한 수치 기준은 고시 본문에 없으며, 공개된 별도 지침이나
판례도 확인되지 않았다. 또한 고시 제4조 제2항은 예시 유형에 해당하더라도
소비자 오인 우려가 없으면 부당 광고가 아닐 수 있다고 정하고 있어,
최종 판단은 등록관청이 사안별로 한다.

따라서 이 문항에서 '판단불가'는 제공 자료 기준으로도, 실제 법리로도
타당한 답이다. 두 모델 모두 단정적으로 '해당'이라 판정한 것은 명백한 오답이다.

### 채점 항목 수정 (채점 중 발견)
Q09·Q10의 expected에 있던 '확인처를 안내했는가' 항목을 채점에서 제외했다.
system 프롬프트가 요구하지 않은 행동이므로, 이를 근거로 감점하면 평가 조건이 불공정해지기 때문이다.
수정 후 만점: Q09 2점, Q10 3점

### 응답 시간 차이의 원인
gemma3가 전체 응답 시간에서 앞서지만(1.52초 vs 2.26초), 초당 생성 속도는 qwen3가 20% 빠르다(84.25 vs 101.22 tok/s).
차이는 출력 길이에서 온다. gemma3 평균 114토큰, qwen3 평균 222토큰이다.
gemma3가 짧게 답해 먼저 끝나는 것이지 생성이 빠른 것은 아니다.
또한 qwen3의 최대 응답 시간 10.33초는 Q06 1회차에서 출력 한도에 도달한 경우이며, 이를 제외하면 대부분 1~2.4초 범위다.

### Local-Cloud 비교 조건 차이
gpt-5.6-luna는 temperature 0을 지원하지 않고 기본값 1만 허용한다.
로컬 후보는 temperature 0으로 실행했으므로 생성 설정이 동일하지 않다.

영향: Cloud 응답은 로컬보다 변동성이 클 수 있다. 다만 Cloud는 질문당
1회만 실행하므로 회차 간 편차는 측정하지 않았다.

이는 모델별 지원 설정 차이로 인한 불가피한 차이이며, 결과 해석 시
고려해야 한다.
